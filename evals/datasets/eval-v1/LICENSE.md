# eval-v1 licence

Every document in this folder is synthetic. The names, numbers, addresses, dates and amounts
are generated by `synth/vault_synth` from a fixed seed; none belongs to a real person,
account or organisation. Identity pages are marked SPECIMEN, Aadhaar-style numbers fail the
Verhoeff checksum, GSTINs fail the GSTIN checksum, any other 12-digit identifier fails
Verhoeff and any 13 to 19 digit identifier fails Luhn, and card numbers are the payment
networks' published test numbers (card statements and letters print only the last four).
PANs, passports, voter cards, licences and certificates are real-shaped but follow a pattern
only this project uses (a leading ZZ); nobody reserves that pattern, so a real number could
look the same by chance.

Released under CC0 1.0 (public domain dedication): https://creativecommons.org/publicdomain/zero/1.0/

The Kannada lines use Noto Sans Kannada, licensed under the SIL Open Font License
(`synth/fonts/OFL.txt`). Fonts are not embedded in the JPEG photos; the PDFs embed a subset.

## Known limit: Kannada lines

The PDFs are drawn with reportlab, which cannot shape Kannada (no conjunct forms, no reph
placement). The `lang: "kn"` line texts in the JSON files are correct Unicode, but the glyphs
on the page are not what a Kannada reader would see. Do not use the Kannada lines to score OCR
or reading accuracy; use them only to check that a pipeline keeps such lines and their boxes.

## What is committed

Only the `val` and `test` splits are committed. The `train` split is regenerated with
`uv run python -m vault_synth --set eval-v1 --splits train --out <folder>`, not committed.
Locked PDFs are encrypted with a random salt, so they differ byte for byte between runs; the
truth files (fields, printed text, line texts, expected questions) are what stays comparable.
