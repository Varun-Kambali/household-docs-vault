# Inbox screens (overrides MASTER.md where they differ)

**One task:** answer the one question the filer could not settle, so the file gets filed.

- One item at a time. The question comes first in the document: in plain words in `--text-heading` ("Whose document is this?"), then what was read, with "Not sure:" in amber where the app doubts it. The page image on `--color-canvas` sits to its left on a wide screen and under it on a phone, so the task is first at every width.
- The answers are radio rows with full labels, keyboard 1 to 9. "File it" is the one primary button, and while it is disabled a line beside it says what enables it ("Choose who this belongs to"). "Skip for now" is secondary. The keyboard hint is hidden on phones.
- The count of waiting items sits beside "Inbox" in the sidebar as plain text ("Inbox 3"), not a badge.
- After filing, a single line confirms where the file went ("Filed in Health / Kavita"), with an Undo link for 10 seconds. A file never disappears without that line. The line has a reserved slot beside the two tool buttons, so it appearing moves nothing under the pointer.
- An empty Inbox says so in one sentence, centred: "Nothing waiting. New files are read as they arrive."
- Activity: the day is a heading over its rows, each row carries only its time, and its actions (Open, Answer, Undo, Retry) are quiet text links. A "Needs a look" row does not repeat the question shown above it, and a file that was never filed has no Undo.
- Keyboard: 1 to 9 choose an answer, Enter files, S skips, Cmd+Z undoes the last filing.
