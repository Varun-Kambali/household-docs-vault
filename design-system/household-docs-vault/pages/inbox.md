# Inbox screens (overrides MASTER.md where they differ)

**One task:** answer the one question the filer could not settle, so the file gets filed.

- One item at a time. Left: the page image on `--color-canvas`. Right: the question in plain words in `--text-heading` ("Whose document is this?"), then what was read, with "Not sure:" in amber where the app doubts it.
- The answers are radio rows with full labels, keyboard 1 to 9. "File it" is the one primary button. "Skip for now" is secondary.
- The count of waiting items sits beside "Inbox" in the sidebar as plain text ("Inbox 3"), not a badge.
- After filing, a single line confirms where the file went ("Filed in Health / Kavita"), with an Undo link for 10 seconds. A file never disappears without that line.
- An empty Inbox says so in one sentence, centred: "Nothing waiting. New files are read as they arrive."
- Keyboard: 1 to 9 choose an answer, Enter files, S skips, Cmd+Z undoes the last filing.
